## 引言

机器学习的研究对象是数据中蕴含的规律，其方法论可概括为：从数据出发构建模型，运用模型进行预测与分析。本文按照由浅入深的顺序，系统介绍现代机器学习实践的核心内容：先阐述学习问题的基础框架与监督学习的两大基本模型（线性回归与逻辑回归），再讲解梯度下降这一贯穿全部模型的优化算法，随后进入神经网络（深度学习）——包括其前向传播机制、激活函数选择、多分类推广与训练细节；之后介绍机器学习工程实践中最重要的诊断方法论（偏差/方差分析、误差分析、数据工程与迁移学习），继而讲解与神经网络并列的另一大算法族——决策树与集成学习；最后进入无监督学习（K-means 聚类与异常检测）、推荐系统（协同过滤与基于内容的过滤）与强化学习（深度 Q 学习）。在关键概念处附有极简 Python 示例与理论补充，文中公式与术语采用机器学习领域的通行表述。

## 学习问题的基础框架

### 机器学习的定义与分类

**Arthur Samuel（1959）** 将机器学习定义为"使计算机无需显式编程即可获得学习能力的研究领域"。其跳棋程序通过数万局自我对弈，从"局面—胜负"的统计关联中学会评估局面，最终棋力超越作者本人。这一案例确立了学习算法的第一条基本规律：**性能随经验（数据）的增加而提升**。**Tom Mitchell（1997）** 给出可操作的形式化定义：计算机程序从经验 E 中学习，若其在任务 T 上的性能度量 P 随 E 的增加而改善——将学习问题分解为任务、性能度量与经验三元组，使"学习"成为可度量、可验证的工程目标。

按照训练信号的类型，学习问题分为三类：

| 范式 | 训练信号 | 学习目标 | 典型应用 |
|---|---|---|---|
| **监督学习** | 输入-标签对 $(x,y)$ | 学习映射 $f:x\mapsto y$ | 房价预测、垃圾邮件过滤、图像识别 |
| **无监督学习** | 仅有输入 $x$ | 发现数据内在结构 | 客户分群、异常检测、降维 |
| **强化学习** | 环境反馈的奖励 | 学习策略最大化累积奖励 | 游戏、机器人控制 |

监督学习是当前工业应用中价值占比最高的范式。其下根据**输出空间的基数**分为两类：**回归**（输出 $y$ 取值于不可数集合，如房价）与**分类**（输出 $y$ 取值于有限集合，如良性/恶性）。判别二者的判据是输出空间的基数而非输出是否以数字编码：分类器输出的 0/1 是类别编码，不存在 0.5 等中间值。

### 记号体系

本文通用的标准记号（贯穿全部模型）：$x$ 为输入特征，$y$ 为输出目标，$\hat{y}$ 为模型预测；$m$ 为训练样本数，$(x^{(i)},y^{(i)})$ 为第 $i$ 个样本（**上标 $(i)$ 为索引而非幂次**）；$n$ 为特征维度。数据集整体称为训练集。

**模型与假设空间**：学习算法的输出是函数 $f$（模型），$f$ 属于由参数索引的**假设类**（hypothesis class）$\mathcal{F}$。例如线性模型的假设类为 $\mathcal{F}=\{f_{w,b}(x)=wx+b\}$。训练即在该假设类中搜索使经验损失最小的参数。这一"假设类 + 经验风险最小化"的视角统一了线性回归、逻辑回归、神经网络乃至决策树的表述——所有模型的差异仅在于假设类的形式与损失函数的选择。

## 线性回归与梯度下降

### 线性回归模型

**单变量模型**：$f_{w,b}(x) = wx + b$，参数 $w$（权重）决定直线斜率，$b$（偏置）决定截距。模型选择问题由此转化为参数搜索问题。**多元线性回归**引入向量记号：设 $n$ 个特征 $\mathbf{x}=[x_1,\dots,x_n]^T$，参数向量 $\mathbf{w}=[w_1,\dots,w_n]^T$，则

$$f_{\mathbf{w},b}(\mathbf{x}) = \mathbf{w}\cdot\mathbf{x} + b = \sum_{j=1}^{n}w_jx_j + b$$

### 损失函数：均方误差与最小二乘

**损失函数（经验风险）** 衡量参数在训练集上的拟合程度，对回归采用**均方误差（MSE）**：

$$J(\mathbf{w},b) = \frac{1}{2m}\sum_{i=1}^{m}\left(f_{\mathbf{w},b}(\mathbf{x}^{(i)}) - y^{(i)}\right)^2$$

系数 $\frac{1}{2}$ 为化简约定（使求导时因子 2 抵消）。优化目标为 $\min_{\mathbf{w},b} J(\mathbf{w},b)$，即最小二乘。

> **理论补充：最小二乘与极大似然估计的等价性。** 设数据生成过程为 $y = \mathbf{w}\cdot\mathbf{x}+b+\varepsilon$，噪声 $\varepsilon\sim\mathcal{N}(0,\sigma^2)$ i.i.d.。则观测数据的对数似然为 $-\frac{1}{2\sigma^2}\sum(f-y)^2$ 加常数项，最大化对数似然等价于最小化 $\sum(f-y)^2$。即**高斯噪声假设下的极大似然估计（MLE）与最小二乘完全等价**——这为平方损失提供了统计正当性，也预示了逻辑回归中"交叉熵 = 伯努利假设下的负对数似然"的平行结构。

**凸性分析**：$J$ 关于参数为二次型，Hessian 矩阵半正定，故 $J$ 是**凸函数**——任何局部极小值即为全局极小值，梯度下降可保证收敛到全局最优点。该性质对非凸问题（如神经网络）不成立。

### 梯度下降算法

梯度下降是机器学习最核心的优化算法，不仅用于线性回归，也用于训练最先进的深度神经网络。其思想：沿损失函数**最速下降方向**迭代更新参数：

$$
\begin{aligned}
w_j &\leftarrow w_j - \alpha\frac{\partial J}{\partial w_j} = w_j - \alpha\cdot\frac{1}{m}\sum_{i=1}^{m}\left(f(\mathbf{x}^{(i)})-y^{(i)}\right)x_j^{(i)} \\
b &\leftarrow b - \alpha\frac{\partial J}{\partial b} = b - \alpha\cdot\frac{1}{m}\sum_{i=1}^{m}\left(f(\mathbf{x}^{(i)})-y^{(i)}\right)
\end{aligned}
$$

其中 $\alpha$ 为**学习率**（步长）。关键细节：

- **同步更新**：每轮须基于更新前的参数值同时计算并更新所有参数（先求右侧、后统一赋值）；非同步更新改变算法性质，不应采用；
- **学习率过小**：收敛缓慢；**学习率过大**：更新越过极小点，损失不降反升，算法**发散**；
- **步长自动衰减**：靠近极小点时梯度范数递减，即使 $\alpha$ 固定，实际位移 $\alpha\|\nabla J\|$ 也自然减小，这是固定步长下仍能收敛的机制；
- **批量梯度下降**：每步使用全部训练样本计算梯度。

> **理论补充：收敛率。** 对 $L$-光滑凸函数，梯度下降以 $O(1/k)$ 速率收敛（$k$ 为迭代次数）；对强凸函数（最小二乘即属此类），收敛率为线性 $O(\rho^k)$。这解释了线性回归实践中收敛较快的原因。

### 向量化：让计算更快

**向量化（vectorization）** 以 `np.dot(w, x)` 或矩阵乘法完成全部 $n$ 次乘加，其高效性源于底层**并行硬件**——现代 CPU 的 SIMD 指令集与 GPU 可对向量元素并行运算，将 $O(n)$ 步串行计算压缩为常数深度的并行运算（并行宽度仍为 $O(n)$）。当 $n$ 与 $m$ 很大时，向量化与显式循环的运行时间差异可达数量级（分钟级 vs 小时级）。

**理论补充：正规方程（Normal Equation）。** 最小二乘存在解析解：设设计矩阵 $X$（含偏置列），则 $\mathbf{w}^* = (X^TX)^{-1}X^Ty$。该解无需迭代，但有局限：① 仅适用于参数线性的模型（逻辑回归、神经网络均不适用）；② 矩阵求逆 $O(n^3)$，特征数大时不可行；③ $X^TX$ 可能奇异或病态。工程上梯度下降是通用方案，成熟库（如 scikit-learn 的 `LinearRegression`）后台可能采用正规方程或其数值改进（SVD）。

### 特征缩放与收敛诊断

**特征缩放（Feature Scaling）**：特征取值范围差异悬殊（如面积 300–2000 vs 卧室数 0–5）时，损失函数等高线呈高离心率椭圆，梯度下降沿法向振荡（zigzag），收敛极慢。三种方法（$\mu_j,\sigma_j$ 为特征 $j$ 的均值与标准差）：

| 方法 | 变换 | 结果范围（示例） |
|---|---|---|
| 最大值归一化 | $x_j \leftarrow x_j/\max_j$ | $(0,1]$ |
| 均值归一化 | $x_j \leftarrow (x_j-\mu_j)/(\max_j-\min_j)$ | 约 $[-0.5,0.5]$ |
| Z-score 归一化 | $x_j \leftarrow (x_j-\mu_j)/\sigma_j$ | 约 $[-2,2]$ |

（"约 $[-0.5,0.5]$ / 约 $[-2,2]$"以示例特征分布估算，实际范围随数据分布而定。）

经验准则：使各特征取值大致落于 $[-1,1]$ 附近。**理论背景**：梯度下降收敛速度受 Hessian 矩阵条件数 $\kappa=\lambda_{\max}/\lambda_{\min}$ 制约；缩放使 $\kappa\to 1$，收敛显著加速。多项式特征（$x^2$ 范围可膨胀至 $10^6$）出现时，缩放由"建议"变为"必需"。

**收敛诊断**：绘制"迭代次数 vs 损失"的**收敛曲线**，正常应逐轮单调下降；某轮上升指示学习率过大或实现缺陷。自动收敛测试（单轮下降量小于阈值 $\varepsilon$）阈值选择困难，曲线观察更可靠。调参惯例：按约 3 倍递增尝试 $\alpha\in\{0.001,0.003,0.01,\dots\}$，选下降快且稳定的最大合理值。

### 特征工程与多项式回归

**特征工程（Feature Engineering）**：基于领域知识，通过变换或组合原始特征构造新特征（如以"临街宽度 $\times$ 进深"构造面积特征），本质是重新设计输入表示以降低学习难度。**多项式回归**将原始特征提升幂次作为新特征（$x^2, x^3, \sqrt{x}$ 等），使线性模型在特征空间中表达非线性关系（对参数仍是线性的，求解框架不变）。

**Python 示例**：单变量线性回归的梯度下降实现。

```python
import numpy as np

def compute_cost(X, y, w, b):
    m = X.shape[0]
    return 1 / (2 * m) * np.sum((w * X + b - y) ** 2)

def compute_gradient(X, y, w, b):
    m = X.shape[0]
    err = w * X + b - y
    dj_dw = np.sum(err * X) / m
    dj_db = np.sum(err) / m
    return dj_dw, dj_db

X = np.array([1., 2., 3.])          # 三个训练样本（单特征）
y = np.array([1., 2., 3.])          # 目标值
w, b, alpha, iters = 0., 0., 0.1, 5000

for _ in range(iters):              # 同步更新 w、b
    dj_dw, dj_db = compute_gradient(X, y, w, b)
    w, b = w - alpha * dj_dw, b - alpha * dj_db
print(f"w={w:.3f}, b={b:.3f}, cost={compute_cost(X, y, w, b):.4f}")
```

运行结果：

```
w=1.000, b=0.000, cost=0.0000
```

梯度下降从 $(0,0)$ 出发迭代 5000 步后逼近最优直线 $y=x$（损失趋近 0）。注意：固定步长下的收敛速度取决于步长与代价曲率的匹配——本例二次代价的两个方向曲率差异不大，$\alpha=0.1$ 即可较快收敛；若步长过小则收敛极慢（100 步时 $w$ 仅到 0.95 左右），过大则振荡发散。

## 逻辑回归：分类的基础模型

### 分类问题与线性回归的局限

分类的输出是有限离散类别（$y\in\{0,1\}$ 为二元分类；0 为负类，1 为正类，"正/负"仅表示目标性质的存在与否）。**线性回归用于分类的两大缺陷**：① 输出无界（可小于 0 或大于 1，与概率语义冲突）；② 决策边界受离群样本影响——新增远离数据主体的样本会使最小二乘直线整体偏移，改变既有样本的分类结论。因此需要输出恒在 $[0,1]$ 内的模型——逻辑回归（logistic regression，亦译逻辑斯谛回归）。

### Sigmoid 函数与逻辑回归模型

**Sigmoid（logistic）函数**：$g(z) = \frac{1}{1+e^{-z}}$，值域 $(0,1)$，$g(0)=0.5$，单调递增，且导数满足 $g'(z)=g(z)(1-g(z))$（该恒等式是梯度推导的关键）。

**逻辑回归模型**：$f_{\mathbf{w},b}(\mathbf{x}) = g(\mathbf{w}\cdot\mathbf{x}+b) = \frac{1}{1+e^{-(\mathbf{w}\cdot\mathbf{x}+b)}}$。

**概率解释**：$f_{\mathbf{w},b}(\mathbf{x}) = P(y=1\mid\mathbf{x};\mathbf{w},b)$——给定输入与参数下正类的条件概率。

**决策边界**：预测规则 $f\ge 0.5 \Rightarrow \hat{y}=1$。由于 $g(z)\ge 0.5 \iff z\ge 0$，等价判定为 $\hat{y}=1 \iff \mathbf{w}\cdot\mathbf{x}+b\ge 0$——决策边界即超平面 $\mathbf{w}\cdot\mathbf{x}+b=0$。引入多项式特征后边界可为任意非线性曲线（如 $z=x_1^2+x_2^2-1$ 产生圆形边界）。不使用多项式特征时，决策边界恒为线性。

### 交叉熵损失函数

**平方误差为何不适用**：将 $f=g(\mathbf{w}\cdot\mathbf{x}+b)$ 代入平方误差后，$J$ 关于参数**非凸**（出现多个局部极小），梯度下降无法保证收敛到全局最优。

**单样本损失**（分段形式）：

$$\text{loss}(f,y) = \begin{cases} -\log f, & y=1 \\ -\log(1-f), & y=0 \end{cases}$$

**简化形式**（利用 $y\in\{0,1\}$ 合并两分支）：

$$\text{loss}(f,y) = -y\log f - (1-y)\log(1-f)$$

**整体损失函数**：$J(\mathbf{w},b) = -\frac{1}{m}\sum_{i=1}^{m}\left[y^{(i)}\log f(\mathbf{x}^{(i)}) + (1-y^{(i)})\log(1-f(\mathbf{x}^{(i)}))\right]$，为凸函数。

> **理论补充：交叉熵的极大似然推导。** 逻辑回归把条件概率建模为伯努利分布 $P(y\mid\mathbf{x})=f^y(1-f)^{1-y}$，训练集对数似然的负值恰为上述损失之和——**最小化交叉熵 ≡ 极大似然估计**。与回归中 MSE 源于高斯假设对应，交叉熵源于**伯努利假设**——"损失函数应匹配输出分布假设"是贯穿全部监督模型的设计原则。

### 逻辑回归的梯度下降

对损失函数求偏导（利用 $g'=g(1-g)$）：

$$\frac{\partial J}{\partial w_j} = \frac{1}{m}\sum_{i=1}^{m}\left(f(\mathbf{x}^{(i)}) - y^{(i)}\right)x_j^{(i)}, \qquad \frac{\partial J}{\partial b} = \frac{1}{m}\sum_{i=1}^{m}\left(f(\mathbf{x}^{(i)}) - y^{(i)}\right)$$

**与线性回归形式一致但本质不同**：上式与线性回归梯度形式完全相同，差异仅在 $f$ 的定义——线性回归 $f=\mathbf{w}\cdot\mathbf{x}+b$，逻辑回归 $f=g(\mathbf{w}\cdot\mathbf{x}+b)$。该梯度的结构（误差项 $(f-y)$ 乘以特征）是广义线性模型与神经网络反向传播的共同形式，逻辑回归可视为单神经元网络。

**Python 示例**：逻辑回归的损失与梯度。

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def compute_cost_logistic(X, y, w, b):
    m = X.shape[0]
    f = sigmoid(X @ w + b)                    # 模型输出（概率）
    loss = -y * np.log(f) - (1 - y) * np.log(1 - f)
    return np.sum(loss) / m

def compute_gradient_logistic(X, y, w, b):
    m = X.shape[0]
    err = sigmoid(X @ w + b) - y
    return (X.T @ err) / m, np.sum(err) / m

X = np.array([[1., 2.], [2., 1.], [3., 4.], [4., 3.]])
y = np.array([0, 0, 1, 1])
w, b = np.zeros(2), 0.
print(f"初始损失: {compute_cost_logistic(X, y, w, b):.4f}")   # 应为 ln2 ≈ 0.693
```

运行结果：

```
初始损失: 0.6931
```

初始损失恰为 $\ln 2\approx 0.693$——当 $f=0.5$（完全不确定）时对数损失的取值，符合直觉。

## 神经网络与深度学习

### 神经元与层

**人工神经元 = 逻辑回归单元**：$a = g(\mathbf{w}\cdot\mathbf{x}+b)$。多个神经元并列构成**层（layer）**：一层输入一个向量，输出另一个向量（各神经元输出组成的激活向量）。

**记号体系**（方括号上标为**层索引**）：$a^{[l]}_j$ 为第 $l$ 层第 $j$ 个神经元的激活值；$W^{[l]}, \mathbf{b}^{[l]}$ 为第 $l$ 层参数；$\mathbf{a}^{[0]}=\mathbf{x}$ 为输入层；网络层数**不包含输入层**。逐层计算：

$$\mathbf{a}^{[l]} = g\left(W^{[l]}\mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}\right)$$

**前向传播（forward propagation / inference）**：从输入逐层计算 $\mathbf{a}^{[1]}\to\cdots\to\mathbf{a}^{[L]}=f(\mathbf{x})$。以手写数字识别为例：8×8 图像（64 个像素亮度值）→ 隐藏层 1（25 单元）→ 隐藏层 2（15 单元）→ 输出层（1 单元，Sigmoid 输出概率）。架构惯例：隐藏单元数沿层递减。

### 神经网络的表示能力：特征层次

以人脸识别为例（输入 1000×1000 像素 = 100 万维向量）：**第一层**检测短边缘/线段；**第二层**组合边缘检测眼睛、鼻尖等面部部件；**第三层**组合部件检测完整脸型。**关键结论：这些特征检测器完全由数据自动学得**，无需人工设计——这是神经网络区别于传统特征工程的核心优势，也是"深度学习 = 表示学习"的直观体现。

### 深度学习为何兴起

横轴为数据量、纵轴为性能：传统算法（线性回归、逻辑回归）的性能随数据量增加很快饱和；而小、中、大神经网络的性能随数据量持续上升，且网络越大上升越陡。数字化社会带来海量数据，GPU 提供并行算力，"大模型 + 大数据"范式使深度学习在语音、图像、自然语言等领域取得突破。理解这一背景是把握后续偏差/方差讨论的关键。

### TensorFlow 实现与数据表示

**数据表示**：NumPy 中单样本特征可用 1D 数组；TensorFlow 统一用**矩阵（2D 数组）**表示数据（$m$ 个样本为 $m\times n$ 矩阵），内部计算更高效。TensorFlow 中的矩阵类型为 **tensor**（可视为矩阵的别名，浮点默认 float32）；`tensor.numpy()` 可转回 NumPy 数组。

**Sequential 范式**：`Sequential([Dense(25, activation='relu'), Dense(15, activation='relu'), Dense(1, activation='sigmoid')])` 将层顺序串联；`model.compile(loss=...)` 指定损失；`model.fit(X, Y, epochs=100)` 训练；`model.predict(X_new)` 推理。理解底层计算仍是调试（bug、慢速、异常结果）的关键能力。

### 激活函数的选择

**输出层选择规则**（由目标 $y$ 的性质决定）：$y\in\{0,1\}$ 用 Sigmoid；$y$ 可正可负用线性；$y$ 非负用 ReLU。**隐藏层默认 ReLU**：计算快（仅 $\max$ 运算），且正半轴导数为常数 1，能避免 Sigmoid 的**梯度衰减**——Sigmoid 两端饱和（导数趋近 0），深层网络中误差信号逐层缩小、学习极慢。

> **理论补充：为什么需要非线性激活。** 若所有层均用线性激活，则任意深度的网络整体仍是线性函数（线性函数复合仍是线性函数），表达能力与单层无异。推论：隐藏层全线性 + 输出线性 → 等价于线性回归；隐藏层全线性 + 输出 Sigmoid → 等价于逻辑回归。**必须引入非线性激活函数才能让深度产生新能力。**

### 训练神经网络：三步法

与训练逻辑回归同构的三步：① **指定模型**：`Sequential` 定义架构；② **指定损失**：二元分类用 BinaryCrossentropy、回归用 MeanSquaredError、多分类用 SparseCategoricalCrossentropy；③ **最小化损失**：`model.fit` 内部执行**反向传播（backpropagation）**计算各参数偏导，再以梯度下降（或 Adam）更新。epoch 即一次完整数据遍历。

### 多分类与 Softmax

**多分类（multiclass）**：$y$ 可取 $K>2$ 个离散值。**Softmax 回归 = 逻辑回归向多分类的推广**：对每个类别 $j$ 计算线性得分 $z_j=\mathbf{w}_j\cdot\mathbf{x}+b_j$，再归一化为概率：

$$a_j = \frac{e^{z_j}}{\sum_{k=1}^{K}e^{z_k}}, \qquad j=1,\dots,K$$

性质：$\sum_j a_j = 1$（概率分布）；$K=2$ 时退化为逻辑回归。**损失函数（交叉熵）**：单样本损失只取真实类别对应的负对数概率 $\text{loss}=-\log a_y$，同样等价于多项分布下的极大似然估计。

**Softmax vs 其他激活**：Sigmoid/ReLU/线性激活是**逐元素**作用于各 $z_j$；Softmax 的每个 $a_j$ 依赖**全部** $z_1..z_K$（归一化分母耦合）。

> **辨析：多分类 vs 多标签。** 多分类中 $y$ 是单一整数（如手写数字 0-9 之一）；多标签（multilabel）中 $y$ 是向量（如"图中是否有车/公交/行人"三个独立二分类）。多标签用**多个 Sigmoid 单元**（每标签一个独立概率），而非 Softmax。

### Softmax 的数值稳定实现

**浮点舍入误差问题**：`2/10000` 直接计算与 `(1+1/10000)-(1-1/10000)` 结果不同——后者引入舍入误差（计算机以有限位二进制存储浮点数，在 float32 等低精度下尤为明显）。Softmax 中 $e^{z_j}$ 在 $z_j$ 很大时爆炸、很小时下溢，若先显式计算 $a_j$ 再算损失，误差被放大。

**改进实现**：输出层用**线性激活**输出 $z_1..z_K$（logits），把"Softmax + 交叉熵"整体交给损失函数（TensorFlow 中 `from_logits=True`），允许框架重排表达式避免显式计算中间概率。代价是代码可读性略降，且推理时需自己对 logits 施加 Softmax 才得到概率。通常推荐始终使用该版本。

### 卷积神经网络（CNN）的基础结构

**为什么需要 CNN**：全连接网络把图像展平成一维向量，既丢失了像素的**空间结构**，又导致**参数爆炸**（28×28 图像展平后 784 维，1000×1000 图像则是 100 万维，全连接层的参数量随之天文数字）。**卷积神经网络（convolutional neural network，CNN）** 通过两个核心设计解决这一问题：

- **局部连接（感受野）**：每个**卷积核（filter）**只与输入的一个**局部窗口**做卷积运算（如 3×3 区域），检测局部模式（边缘、角点、纹理）。该局部窗口即该输出单元对应的**感受野（receptive field）**。卷积核滑过整幅图像，输出对应的**特征图（feature map）**；多个卷积核并列，各自检测一种特征；
- **权值共享**：同一个卷积核在整个图像上滑动时参数不变——同一特征无论出现在画面哪个位置都能被识别（**平移不变性**），且参数量只取决于卷积核大小而非图像尺寸。

**池化（pooling）**：在卷积之后对特征图降采样（如 2×2 区域取最大值），压缩尺寸、减少计算量，并增强对微小位移的鲁棒性。典型结构是"卷积 + ReLU + 池化"交替堆叠，逐层抽象出从边缘到部件再到物体的特征，末端接全连接层输出分类。

**为什么 CNN 适合图像**：图像的统计特性具有局部性与平移不变性——CNN 的局部连接与权值共享恰好内建了这两条先验，因此比同规模全连接网络参数量更少、更易训练、更不易过拟合。卷积层思想同样适用于一维信号（如 ECG：每单元只看 20 个连续时间点，即卷积层的直观例子）。Transformer、LSTM、attention 等现代架构本质都是对"层"这一概念的拓展，本文不再展开。

### Adam 优化器

**动机**：标准梯度下降用单一全局学习率。若损失曲面等高线呈拉长椭圆，沿长轴方向步长不足、沿短轴方向来回振荡——固定 $\alpha$ 无法同时满足两轴需求。

**Adam（Adaptive Moment Estimation）**：为**每个参数维护独立的自适应学习率**。若参数持续沿同一方向移动（梯度符号稳定），增大其 $\alpha_j$ 加速；若来回振荡（梯度符号频繁翻转），减小其 $\alpha_j$ 抑制振荡。实践中：对学习率初值更鲁棒（仍建议尝试几档初值），训练速度通常显著快于梯度下降，已成为训练神经网络的事实标准。

## 泛化：偏差、方差与正则化

### 过拟合与欠拟合

**泛化（Generalization）** 是机器学习的根本目标：在未见样本上表现良好。模型的三种状态：

| 状态 | 技术术语 | 表现 | 成因 |
|---|---|---|---|
| 欠拟合 | **高偏差（high bias）** | 训练误差与测试误差均高 | 模型容量不足 |
| 恰适 | just right | 训练与泛化俱佳 | 容量与数据复杂度匹配 |
| 过拟合 | **高方差（high variance）** | 训练误差极低（可至 0）、泛化差 | 容量过大 |

过拟合的本质：模型**记忆了训练集的噪声**而非规律，对训练数据的微小扰动高度敏感。特征数远大于样本数时尤其易发。

### 偏差-方差分解

对测试点 $x$，设真实函数为 $f^*$，模型预测的期望均方误差可分解为：

$$\mathbb{E}\left[(f(x)-f^(x))^2\right] = \underbrace{\left(\mathbb{E}[f(x)]-f^(x)\right)^2}{\text{偏差}^2} + \underbrace{\mathbb{E}\left[(f(x)-\mathbb{E}[f(x)])^2\right]}{\text{方差}} + \underbrace{\sigma^2}_{\text{不可约噪声}}$$

**偏差**对应欠拟合（模型假设与真实函数的系统性偏离），**方差**对应过拟合（模型对训练集变化的敏感度），**不可约噪声**无法消除。偏差与方差之间存在权衡：增大模型容量降低偏差但升高方差。这一框架是工程诊断方法论的理论基础。

### 正则化

**正则化损失函数**（以线性回归为例）：

$$J(\mathbf{w},b) = \underbrace{\frac{1}{2m}\sum_{i=1}^{m}\left(f(\mathbf{x}^{(i)})-y^{(i)}\right)^2}\_{\mathrm{拟合项}} + \underbrace{\frac{\lambda}{2m}\sum_{j=1}^{n}w_j^2}_{\mathrm{正则化项}}$$

$\lambda$ 为**正则化参数**，权衡"拟合训练数据"与"约束参数幅值"两个目标。$\lambda=0$ 无正则化 → 过拟合；$\lambda\to\infty$ 参数被压至近 0，模型退化为常数 → 欠拟合。合适值介于其间。

> **理论补充：L2 正则化的贝叶斯解释。** 对参数施加高斯先验 $w_j\sim\mathcal{N}(0,1/\lambda')$ 并求最大后验估计（MAP），目标函数恰为"负对数似然 + $\ell_2$ 惩罚"。故 $\ell_2$ 正则化（Ridge）≡ 高斯先验下的 MAP 估计。平行地，拉普拉斯先验对应 $\ell_1$ 正则化（LASSO），其解具有稀疏性（部分参数恰为 0），可实现自动特征选择。

**正则化梯度下降**：仅 $w_j$ 更新附加 $\frac{\lambda}{m}w_j$ 项，整理为 $w_j\leftarrow w_j\left(1-\alpha\frac{\lambda}{m}\right) - \alpha\frac{1}{m}\sum(f-y)x_j$——因子 $\left(1-\alpha\frac{\lambda}{m}\right)$ 略小于 1，即每轮先对 $w_j$ 施加轻微**收缩（shrinkage）**再执行常规更新，这是正则化"温和压缩参数"的微观机制。逻辑回归同理（交叉熵后追加 $\frac{\lambda}{2m}\sum w_j^2$）。

另一种常用的正则化手段是**丢弃法（Dropout）**——训练时随机丢弃部分隐藏神经元，迫使网络学习鲁棒表示。

## 模型诊断与工程实践

### 迭代式开发循环

ML 系统开发的常态循环：**选择架构 → 实现并训练 → 诊断（偏差/方差、误差分析）→ 基于诊断决策（加大网络/调 λ/加数据/加特征）→ 再次循环**。首次训练的模型几乎从不满足要求；诊断决定每次迭代的方向。以垃圾邮件分类为例，改进候选很多（收集更多数据、邮件路由特征、拼写错误检测），仅凭直觉选择可能浪费数月——正确做法是用偏差/方差诊断 + 误差分析筛选方向。

### 数据集划分：训练 / 交叉验证 / 测试

**为什么训练误差不可信**：参数在训练集上拟合，训练误差系统性地低于真实泛化误差。**为什么测试集不能用于模型选择**：若用测试集选模型阶数 $d$，则 $d$ 间接拟合了测试集，测试误差成为过于乐观的泛化估计。

**正确流程（三划分）**：数据按约 60%/20%/20% 分为训练集、交叉验证集（dev set）、测试集。① 用训练集拟合各模型的参数；② 用交叉验证集计算 $J_{cv}$ 选择模型（超参数 $d$、$\lambda$、网络结构）；③ 模型选定后**仅用测试集**计算 $J_{test}$ 作为泛化误差的无偏估计。纪律要求：**所有模型决策只能看训练集与交叉验证集，测试集直到最终评估前不得使用**。

### 偏差与方差诊断

**基本判据**：**高偏差** → $J_{train}$ 高（连训练集都拟合不好）；**高方差** → $J_{cv}\gg J_{train}$（训练集拟合很好但未见数据表现差）。

**基线水平（baseline）**：判断"高"需相对基准——合理期望达到的最低误差（人类水平、既有算法、经验估计）。**修正判据**（两个关键差值）：$J_{train}-\text{baseline}$ 大 → 高偏差；$J_{cv}-J_{train}$ 大 → 高方差。例：$J_{train}=10.8\%, J_{cv}=14.8\%$，人类基线 10.6% → 偏差仅 0.2%（低偏差）、方差 4%（高方差）——与"只看绝对值判高偏差"的直觉相反。**高偏差与高方差可同时存在**。

### 学习曲线

**定义**：横轴为训练集规模 $m_{train}$，纵轴为误差，同时绘制 $J_{train}$ 与 $J_{cv}$。形态：$m$ 很小时 $J_{train}\approx 0$，随 $m$ 增大而上升；$J_{cv}$ 随 $m$ 增大而下降；$J_{cv}$ 恒不低于 $J_{train}$。

**诊断价值**：**高偏差** → 两曲线很快趋于平坦且 $J_{train}$ 停在基线之上——**增加数据基本无效**（模型太简单），应换更复杂模型；**高方差** → $J_{cv}$ 与 $J_{train}$ 之间存在大 gap 且 $J_{cv}$ 仍在下降——**增加数据很可能有效**。

### 误差分析

**定义**：人工逐条检查交叉验证集中的错分类样本（约 100 个），归纳错误类型并计数。例：100 个错分垃圾邮件中——药物推销 21 个、钓鱼 18 个、非常规路由 7 个、刻意拼写错误 3 个。**指导价值**：计数量化各类错误的边际收益——即使做出完美拼写错误检测也只改善 3/100，优先级低；针对大错误类可定向收集数据、构造特征。局限：仅适用于人类能判断的任务（人无法预测广告点击）。

### 决策表：诊断驱动的下一步行动

| 状态 | 判据 | 有效对策 | 无效对策 |
|---|---|---|---|
| **高方差** | $J_{cv}\gg J_{train}$ | 更多数据；简化模型（减特征、增 λ） | — |
| **高偏差** | $J_{train}$ 高（相对基线） | 加特征；加多项式特征；减 λ；加大网络 | 更多数据（基本无效）；减少训练样本（反而恶化） |

**神经网络特例**：足够大的神经网络在中等规模数据上是**低偏差机器**（几乎总能拟合训练集），因此针对网络有专门配方：$J_{train}$ 高 → 加大网络；$J_{cv}$ 高 → 增加数据；循环直至达标。经验结论：只要恰当正则化，更大网络几乎总不差于小网络（代价仅为算力），故网络场景中方差问题比偏差问题更常见。

### 数据工程：定向数据、增强与合成

- **定向收集**：误差分析指示某类是大问题 → 优先收集该类数据，而非"多多益善"；
- **数据增强（data augmentation）**：对已有样本施加保持标签不变的失真变换生成新样本（图像：旋转、缩放、对比度调整；音频：叠加背景噪声、模拟差手机连接）。**关键准则**：变换须代表测试集中的真实失真——加入测试集不会出现的无意义像素噪声帮助甚微；
- **数据合成（data synthesis）**：从零生成逼真样本（如用计算机字体 + 随机颜色/对比度合成照片 OCR 文本图像）。体现**数据为中心（data-centric）**的方法论：算法成熟后，工程数据的收益常大于再调模型。

### 迁移学习

**设定**：目标任务标注数据少。**两步流程**：① **监督预训练**：在大数据集（如 100 万张图、1000 类）上训练网络；② **微调（fine-tuning）**：保留前 $L-1$ 层参数、替换输出层（类别数不同须重训）——小数据集仅训练新输出层，数据稍多则全部参数以预训练值初始化继续训练。**为何有效**：预训练使前几层学会通用低级特征（边缘→角→基本形状），对许多任务通用。**限制**：预训练与微调的输入类型须一致（图像预训练不能用于音频）。实践中常直接下载开源预训练模型（ImageNet、BERT、GPT-3 均为迁移学习的成功实例）微调。

### 偏斜数据集：精确率、召回率与 F1

**问题**：罕见病检测中仅 0.5% 患者患病。恒输出 $y=0$ 的"算法"准确率 99.5%，反超真实学习算法——准确率在类别严重失衡时失去意义。

**混淆矩阵**：按"实际类 × 预测类"分为真正例 TP、假正例 FP、假负例 FN、真负例 TN。

**精确率（Precision）**——预测为正的样本中实际为正的比例：$P = \frac{TP}{TP+FP}$。

**召回率（Recall）**——实际为正的样本中被正确检出的比例：$R = \frac{TP}{TP+FN}$。恒输出 0 的算法 $R=0$，被立即识破。

**精确率-召回率权衡**：提高预测阈值 → 更谨慎 → 精确率升、召回率降（适合治疗副作用大的场景）；降低阈值 → 更激进 → 召回率升、精确率降（适合漏诊后果严重的场景）。阈值选择反映假阳/假阴的成本权衡，属业务决策，无法用交叉验证自动确定。

**F1 分数（调和平均）**：$F_1 = \frac{2PR}{P+R}$。为何不用算术平均：恒预测 $y=1$ 的算法 $R=1, P$ 极低，算术平均可观但算法无用；调和平均在任一值很小时整体很低，正确惩罚"偏科"。

### 类别不平衡工具箱

上一节说明了"不平衡时该看什么指标"，本节回答"然后怎么办"。手法分三类——**改损失**、**改数据**、**改决策**——三者的侵入性依次递减，建议按**由轻到重**的顺序尝试。

#### 改损失：类别权重与代价敏感

最轻的做法不动数据、只改损失函数：给少数类的样本乘一个更大的权重，让"漏掉一个少数类"的惩罚与"漏掉多个多数类"相当。二类问题中，把权重取为类别频率的倒数是最常见的起点：

$$w_c = \frac{N}{C \cdot N_c} \quad\Rightarrow\quad \text{少数类权重} \approx \frac{\text{多数类样本数}}{\text{少数类样本数}}$$

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (average_precision_score, precision_score,
                             recall_score, f1_score)

X, y = make_classification(n_samples=20000, n_features=20, n_informative=6,
                           weights=[0.99, 0.01], flip_y=0.01, random_state=0)
Xtr, Xte, ytr, yte = X[:12000], X[12000:], y[:12000], y[12000:]
print('训练集正例占比:', round(ytr.mean(), 4), '| 测试集正例占比:', round(yte.mean(), 4))

def report(tag, score, thr=0.5):
    pred = (score >= thr).astype(int)
    print(f'{tag:26s} AP={average_precision_score(yte, score):.3f} '
          f'P={precision_score(yte, pred, zero_division=0):.3f} '
          f'R={recall_score(yte, pred, zero_division=0):.3f} '
          f'F1={f1_score(yte, pred, zero_division=0):.3f}')

base = LogisticRegression(max_iter=2000).fit(Xtr, ytr)
report('无处理（阈值 0.5）', base.predict_proba(Xte)[:, 1])

w_bal = LogisticRegression(max_iter=2000, class_weight='balanced').fit(Xtr, ytr)
report('class_weight=balanced', w_bal.predict_proba(Xte)[:, 1])

# 显式代价敏感：漏检代价是误报的 9 倍 -> 等价于给正类样本加权 9
w_dict = {0: 1.0, 1: 9.0}
w_cost = LogisticRegression(max_iter=2000, class_weight=w_dict).fit(Xtr, ytr)
report('class_weight={0:1, 1:9}', w_cost.predict_proba(Xte)[:, 1])
```

> **注意 AUC/AP 不随权重改变而改变**（对同一模型族而言，加权会改变拟合出的决策面，但"排序能力"通常只有小幅变化）。真正被权重改变的是**默认可用的工作点**：不加权时模型会把绝大多数样本判为多数类（召回率接近 0），加权后默认工作点移向少数类（召回率大幅上升、精确率下降）。所以"加权有没有用"要在**同一阈值下**比较，或者干脆用 AP/AUC 比较排序、用代价曲线比较决策。

`class_weight='balanced'` 适合**只关心"别漏掉"**的场景；而 `{0: 1, 1: 9}` 这类显式代价把业务判断写进模型，可解释性更好。代价敏感学习的极端形式是把代价直接写进目标函数（如"每漏检一次罚 100 元、每误报一次罚 10 元"），这在风控与工业报警中很常见。

#### 改数据：重采样与 SMOTE

第二类做法调整训练集的类别构成。**注意：只对训练集动手，验证集与测试集必须保持真实分布**——对测试集做重采样会把"现实中的不平衡"人为抹平，评估结果将完全失真，这是新手最容易犯的评估错误之一。

| 方法 | 做法 | 优点 | 风险 |
|---|---|---|---|
| 随机欠采样 | 随机丢弃多数类样本 | 训练快、缓解不平衡 | **丢信息**；样本少时损害严重 |
| 随机过采样 | 重复少数类样本 | 不丢信息 | **易过拟合**（同一批样本反复出现） |
| SMOTE 及其变体 | 在少数类近邻之间插值生成新样本 | 引入多样性、不只是复制 | 高维/稀疏特征上近邻不可靠；会跨越类别边界生成"不可能样本" |
| 混合（SMOTEENN、SMOTETomek） | 先过采样再清洗噪声与边界样本 | 兼顾两方 | 流程更复杂、计算更贵 |

```python
from imblearn.over_sampling import SMOTE, RandomOverSampler
from imblearn.under_sampling import RandomUnderSampler
from imblearn.pipeline import Pipeline as ImbPipeline

def fit_resampled(sampler, tag):
    pipe = ImbPipeline([('sampler', sampler),
                        ('clf', LogisticRegression(max_iter=2000))])
    pipe.fit(Xtr, ytr)                     # 采样只作用于 fit 内部，预测时不再采样
    report(tag, pipe.predict_proba(Xte)[:, 1])

fit_resampled(RandomUnderSampler(random_state=0), '随机欠采样')
fit_resampled(RandomOverSampler(random_state=0), '随机过采样')
fit_resampled(SMOTE(random_state=0, k_neighbors=5), 'SMOTE')

# SMOTE 的 k 近邻在高维稀疏数据上不可靠：看生成样本与原始样本的距离分布
from sklearn.neighbors import NearestNeighbors
X_res, y_res = SMOTE(random_state=0).fit_resample(Xtr, ytr)
nn = NearestNeighbors(n_neighbors=2).fit(Xtr)
d, _ = nn.kneighbors(X_res[y_res == 1])
print('少数类样本到训练集最近邻的平均距离:', round(d[:, 1].mean(), 3))
```

**SMOTE 什么时候会失效**：① 特征维度远大于样本数（距离度量失去意义，所谓"近邻"已不近）；② 少数类样本被多数类包围（插值会生成落在多数类区域内的假样本，反而制造噪声）；③ 类别不平衡并非"数据少"而是"标签稀有"（如极端事件），此时生成样本等于凭空编造现象，风险极大。**在这三种情况下，改损失或改决策通常比 SMOTE 更稳。**

#### 改决策：阈值移动与 Focal Loss

第三类做法完全不动数据与损失，只改**决策规则**——把阈值从 0.5 移向少数类。这是侵入性最小、也最该优先尝试的一招：上一节已经说明，`predict()` 内部的 0.5 是纯约定，与业务无关。

```python
score = base.predict_proba(Xte)[:, 1]
print('阈值移动的效果（同一模型，只改决策阈值）：')
for thr in (0.5, 0.2, 0.1, 0.05, 0.02, 0.01):
    pred = (score >= thr).astype(int)
    print(f'  thr={thr:<5} P={precision_score(yte, pred, zero_division=0):.3f} '
          f'R={recall_score(yte, pred, zero_division=0):.3f} '
          f'F1={f1_score(yte, pred, zero_division=0):.3f}')
```

对比前面加权的结果可以看出：**加权与阈值移动在很多情况下能达到相近的工作点**。既然如此，优先选阈值移动——它不改变模型、不复制样本、可在线调节、出问题能立刻回退。

**Focal Loss** 是"改损失"的进阶形式，专为**极度不平衡 + 大量易分样本**的场景设计。它把交叉熵中的每个样本按"预测得有多好"加权：

$$\text{FL}(p_t) = -\alpha_t (1-p_t)^{\gamma}\log p_t$$

其中 $p_t$ 是真实类的预测概率，$\gamma$ 是聚焦参数。作用机制：当一个样本已经被预测得很准（$p_t\to 1$）时，$(1-p_t)^\gamma\to 0$，它的损失被压到几乎为零，梯度不再被这些"已经学会的"多数类样本占据；模型因此把学习能力集中在少数难样本与少数类上。$\gamma=0$ 退化为普通加权交叉熵，实践中常用 $\gamma=2$、$\alpha$ 取类别频率的倒数（如 $\alpha=0.25$ 配正类稀少的情形）。它最初用于目标检测（RetinaNet）解决正负样本极度失衡的问题，此后广泛用于分割、排序与异常检测。

```python
import torch
import torch.nn.functional as F

def focal_loss(logits, targets, alpha=0.25, gamma=2.0):
    """Focal Loss：alpha 平衡类别，gamma 压制易分样本"""
    logp = F.log_softmax(logits, dim=-1)
    logpt = logp.gather(1, targets.view(-1, 1)).squeeze(1)
    pt = logpt.exp()
    at = torch.where(targets == 1, alpha, 1 - alpha).float()
    return -(at * (1 - pt) ** gamma * logpt).mean()

# 示意：真实类概率越高，损失被压得越低（gamma 越大越明显）
for pt in (0.9, 0.6, 0.2):
    logit = torch.tensor([[0.0, float(np.log(pt / (1 - pt)))]])
    tgt = torch.tensor([1])
    print(f'  p_t={pt}: 交叉熵 {F.cross_entropy(logit, tgt):.4f} '
          f'-> Focal {focal_loss(logit, tgt):.4f}')
```

#### 决策清单

| 症状 | 首选 | 其次 |
|---|---|---|
| 少数类召回率几乎为 0，但 AP 尚可 | **阈值移动** | 类别权重 |
| 两类错误代价明确不同（漏检更贵） | **代价敏感**（显式代价权重） | 阈值移动（按代价曲线选点） |
| 少数类样本太少（几十条以内） | 类别权重 | 谨慎用 SMOTE（并严格交叉验证） |
| 数据量大、多数类冗余明显 | 随机欠采样 | 混合采样 |
| 高维稀疏特征（文本、one-hot） | 类别权重 | **不要用 SMOTE** |
| 深度模型 + 海量易分负样本 | Focal Loss | 难例挖掘（hard negative mining） |

**最后一条纪律**：任何不平衡处理都**只在训练侧生效**，且必须用**分层交叉验证**（`StratifiedKFold`）来选超参数——否则某折里可能一个少数类样本都没有，指标会剧烈抖动甚至报错。评估时始终在**原始分布**的验证/测试集上，用 AP 与代价曲线而非准确率来判定优劣。

## 决策树与集成学习

### 决策树模型

决策树是以树形结构描述基于特征对实例分类的过程，可视为 if-then 规则的集合（每条根到叶的路径是一条规则，规则互斥且完备），也可视为定义在特征空间划分上的条件概率分布。术语：**根节点**（最上层）、**决策节点**（按特征值分支）、**叶节点**（输出预测）。

**单棵树的弱点**：对训练数据的微小变化高度敏感——改变 1 个样本可能改变根节点分裂特征，产生完全不同的树。**树集成（tree ensemble）**：训练多棵树并对新样本投票，单棵树的波动（方差）被群体平均稀释，整体更稳定、更准确。

### 熵与信息增益

**直觉**：决策树分裂时需要在候选特征中选出"最能区分样本"的一个。信息论给出的标准答案是**熵**——度量节点内样本的**不纯度**：正负样本各半时最不纯（熵最大），全部同属一类时最纯（熵为 0）。**信息增益（information gain）= 分裂前后熵的减少量**：分裂后各子节点熵按样本占比加权求和，再从父节点熵中减去；**选择规则**是计算每个候选特征的信息增益、选增益最大者。CART 分类树另用基尼指数选择特征，实践中与熵效果相近。

### 递归构建与停止准则

**递归构建**：① 从根节点（全部样本）开始，计算所有特征的信息增益，选最大者分裂；② 将样本按特征值送入子节点；③ 对每个子节点递归执行（子树的构建等价于在子集上重新训练决策树）；④ 直至满足停止准则。

**停止准则**（均为超参数，防止树过大/过拟合）：节点样本全部属单一类别（熵为 0）；达到预设最大深度；信息增益低于阈值；节点样本数低于阈值。深度类比：最大深度 ~ 多项式阶数 ~ 网络规模——更大容量、更高过拟合风险，可用交叉验证选择。

### 独热编码与连续特征

**独热编码（one-hot encoding）**：将 $k$ 值类别特征替换为 $k$ 个二元特征（每样本恰一个为 1）。回到二元特征场景，原算法无需修改；同样适用于神经网络等任何需要数值输入的模型。

**连续特征**：对候选阈值 $t$ 按 $x\le t$ 分裂并计算信息增益；阈值候选取排序后样本特征值相邻点的中点（$m$ 个样本 → $m-1$ 个候选），选增益最大的阈值。

**回归树（可选）**：分裂准则用**方差减少（reduction in variance）** $\text{Var}_{\text{root}} - \sum_k w^{k}\text{Var}^{k}$；叶节点预测值为落入该叶样本 $y$ 的均值。

### 随机森林与 XGBoost

**有放回抽样（bootstrap）**：从 $m$ 个样本中有放回抽取 $m$ 次生成新训练集（允许重复、可缺失个别样本）。**Bagged 决策树**：重复 B 次抽样-训练（$B$ 常取 100 量级，更大 B 收益递减），投票集成。

**随机森林 = bagged 树 + 特征随机子集**：每节点分裂时仅从随机选取的 $K<n$ 个特征子集中选择（$K$ 常取 $\sqrt{n}$），进一步降低树间相关性，使投票更有效。

**XGBoost（eXtreme Gradient Boosting）**：最广泛使用的提升树实现。**提升（boosting）** 与随机森林（均匀抽样、并行）相对，是**顺序聚焦**过程：每轮构建新树时对样本加权——此前树集成错分的样本获得更高权重（此叙述承 AdaBoost 的直观；梯度提升实质是拟合残差/负梯度，此处仅为直观类比；刻意练习类比：聚焦薄弱段落练习优于整曲重复）。XGBoost 特点：运行快、默认分裂/停止准则良好、**内置正则化**防过拟合、为样本分配权重而非物理重采样（更高效）。Kaggle 竞赛中 XGBoost 与深度学习是两大常胜算法。

### 决策树 vs 神经网络：选择指南

| 维度 | 决策树/集成 | 神经网络 |
|---|---|---|
| 表格数据（结构化） | 表现良好，值得首选 | 同样有竞争力 |
| 非结构化数据（图像/音频/文本） | 不推荐 | **首选** |
| 训练速度 | **快**（迭代周转快） | 大网络训练慢 |
| 可解释性 | 小树可直接观察决策路径 | 黑箱 |
| 迁移学习 | 不适用 | **支持**（小数据集关键手段） |
| 多模型串联训练 | 只能逐棵训练 | 输出可微，可端到端联合训练 |

工程建议：多数表格任务用 XGBoost；非结构化或需迁移学习时用神经网络。

## 无监督学习：聚类与异常检测

### 无监督学习的定位

无监督学习的训练数据**只有 $x$，没有标签 $y$**，算法需自行发现数据中的结构。三类：**聚类**（将相似样本分组，如 Google News 新闻聚合）、**异常检测**（发现异常事件，如金融欺诈）、**降维**（压缩数据、保留信息）。

### K-means（k 均值）聚类算法

**算法**（迭代两阶段）：

```
初始化 K 个质心 mu_1, mu_2, ..., mu_K
重复直到收敛：
  1. 分配阶段：每个样本归属最近的质心
     c(i) = argmin_j ||x(i) - mu_j||^2
  2. 更新阶段：质心移动到其簇内样本均值
     mu_k = (1/|C_k|) * sum_{i in C_k} x(i)
```

**收敛性**：算法保证收敛到一组质心（损失函数不增），但收敛结果依赖初始化，可能收敛到局部最优。**实践建议**：多次随机初始化，选**失真（distortion）代价** $J=\frac{1}{m}\sum_i\|x^{(i)}-\mu_{c^{(i)}}\|^2$ 最低的解。

> **理论补充：K-means 的收敛性。** 交替迭代保证目标函数单调不增、最终收敛，但收敛结果依赖初始化、可能落入局部最优，失真函数亦可用于选择 $K$（肘部法则）。

### 异常检测：高斯模型

**问题设定**：给定无标签样本（如服务器吞吐量、延迟的 $m=307$ 个观测），绝大多数正常，少数异常。

**高斯分布**：$p(x;\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$

**对每个特征独立估计参数**：$\mu_j = \frac{1}{m}\sum_{i=1}^{m}x_j^{(i)}$，$\sigma_j^2 = \frac{1}{m}\sum_{i=1}^{m}(x_j^{(i)}-\mu_j)^2$

**联合概率**（特征独立性假设）：$p(\mathbf{x}) = \prod_{j=1}^{n}p(x_j;\mu_j,\sigma_j^2)$

**判定**：$p(\mathbf{x}) < \varepsilon$ → 异常。阈值 $\varepsilon$ 用**交叉验证集**选择——对每个候选 $\varepsilon$ 计算验证集上的 $F_1$ 分数（$y=1$ 为异常），选最高者。

> **理论补充：与高斯朴素贝叶斯的联系。** 异常检测对每个特征拟合高斯分布再取乘积，与高斯朴素贝叶斯分类器数学形式相同；区别在于训练数据只有正常样本（无异常标签）或利用验证集标签选阈值，本质是**密度估计 + 阈值**而非直接分类。实践中常计算 $\log p(\mathbf{x})=\sum_j\log p(x_j)$ 避免数值下溢。

**Python 示例**：K-means 核心两阶段。

```python
import numpy as np

def find_closest_centroids(X, centroids):
    idx = np.zeros(X.shape[0], dtype=int)
    for i in range(X.shape[0]):
        dist = np.linalg.norm(X[i] - centroids, axis=1)   # 到各质心的距离
        idx[i] = np.argmin(dist)                          # 归属最近质心
    return idx

def compute_centroids(X, idx, K):
    centroids = np.zeros((K, X.shape[1]))
    for k in range(K):
        centroids[k] = X[idx == k].mean(axis=0)           # 簇内均值
    return centroids

X = np.array([[1., 2.], [1.5, 1.8], [5., 8.], [8., 8.], [1., 0.6], [9., 11.]])
centroids = np.array([[1., 2.], [8., 8.]])               # K=2 的初始质心
idx = find_closest_centroids(X, centroids)
centroids = compute_centroids(X, idx, 2)
print(f"分配结果: {idx}")
print(f"更新后质心:\n{centroids}")
```

## 推荐系统

### 问题设定与两种范式

**设定**：$n_u$ 个用户、$n_m$ 部电影，已知部分"用户-电影"评分（稀疏矩阵），预测缺失评分并推荐（如 MovieLens 数据集）。

| 范式 | 依据 | 能否推荐新物品 |
|---|---|---|
| **协同过滤（Collaborative Filtering）** | 仅从评分矩阵学习用户与物品的向量表示 | 不能 |
| **基于内容的过滤（Content-based Filtering）** | 用户/物品的**特征**经神经网络生成向量 | 能 |

### 协同过滤

**核心思想**：为每个用户学一个"口味向量" $\mathbf{w}^{(u)}$（或参数向量），为每部电影学一个"内容特征向量" $\mathbf{x}^{(m)}$，点积（加偏置）预测评分：$\hat{y}^{(u,m)} = \mathbf{w}^{(u)}\cdot\mathbf{x}^{(m)} + b^{(u)}$。

**学习方式**：同时优化全部用户参数与电影特征，最小化**仅对已有评分**的误差（正则化防过拟合）：

$$J = \frac{1}{2}\sum_{(u,m):r(u,m)=1}\left(\mathbf{w}^{(u)}\cdot\mathbf{x}^{(m)} + b^{(u)} - y^{(u,m)}\right)^2 + \text{正则化项}$$

求和只覆盖已评分（$r=1$）的 $(u,m)$ 对——稀疏矩阵只对观测项惩罚。该损失函数对 $\mathbf{w}$ 与 $\mathbf{x}$ 分别固定对方时均凸，可用梯度下降交替优化（与 K-means 的坐标下降结构类似）。学得向量后，物品间余弦相似度用于"相似电影"推荐。

### 基于内容的过滤

**与协同过滤的区别**：协同过滤的向量仅从评分推导；基于内容的过滤**利用用户/物品的已知特征**（类型独热编码、上映年份、用户各类型平均评分等工程特征），经两个神经网络分别生成用户向量 $\mathbf{v}_u$ 与物品向量 $\mathbf{v}_m$，评分仍为点积 $\hat{y}^{(u,m)} = \mathbf{v}_u\cdot\mathbf{v}_m$。**关键优势**：训练后新物品无需评分即可通过其特征网络生成向量并预测。

### 实现要点

- **均值归一化**：按物品（电影）减去其平均评分后再训练，主要帮助评分很少或未评分的用户获得更合理的预测；
- **正则化**：用户参数与物品特征均加 $\ell_2$ 惩罚（观测数远小于参数数时尤甚）；
- 协同过滤适用于"只有评分"的场景；内容过滤适用于"有特征"且需推荐新物品的场景。

## 强化学习与深度 Q 学习

### 强化学习的设定

监督学习学习固定映射 $x\to y$；强化学习是**智能体（agent）与环境（environment）交互**的序贯决策问题。**智能体-环境循环**：时间步 $t=0,1,2,\dots$，智能体依据**策略（policy）** $\pi$ 观测状态 $S_t$ 选择动作 $A_t$，环境返回奖励 $R_t$ 与新状态 $S_{t+1}$。目标为最大化**折扣累计回报**：$G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \cdots$，$\gamma\in(0,1)$ 为**折扣因子**。

### 状态-动作值函数 Q(s,a)

**定义**：$Q(s,a)$ = 在状态 $s$ 采取动作 $a$ 之后、此后遵循最优策略所能获得的期望折扣回报。**贝尔曼方程（Bellman equation）**——Q 值满足的自洽递推：

$$Q(s,a) = R(s,a) + \gamma\max_{a'}Q(s',a')$$

即当前 Q 值 = 即时奖励 + 折扣 × 下一状态最优动作的 Q 值。**若已知 $Q^*$，最优策略即在每个状态选 $\arg\max_a Q^*(s,a)$**——规划问题简化为查表。该方程是强化学习的基石。

### 深度 Q 学习（Deep Q-Learning）

**问题**：离散小状态空间可用表格（查表法）迭代贝尔曼方程；但**连续状态空间**（如 8 维登月器状态）无法穷举。

**解决**：用**神经网络 $Q(s,a;\mathbf{w})$ 逼近 $Q^*(s,a)$**（Q-Network），以贝尔曼方程为目标训练：目标 $y = R + \gamma\max_{a'}\hat{Q}(s',a';\mathbf{w}^-)$，损失 $=(y - Q(s,a;\mathbf{w}))^2$。

**不稳定性的两个来源与对策**：

1. **目标漂移**：$y$ 依赖当前网络权重，每步都在变，导致训练震荡。对策：**目标网络（Target Network）** $\hat{Q}$——权重拷贝的"慢网络"，软更新 $\mathbf{w}^-\leftarrow\tau\mathbf{w}+(1-\tau)\mathbf{w}^-$（$\tau\ll 1$）使目标变化缓慢、训练稳定；
2. **样本相关性**：连续交互产生的经验序列高度相关，违背独立同分布假设。对策：**经验回放（Experience Replay）**——将转移 $(s,a,r,s')$ 存入缓冲，训练时随机采样小批量，打散相关性、提升样本利用效率。

**探索 vs 利用**：$\varepsilon$-贪心——小概率随机动作保证探索新状态，否则利用当前最优；训练中 $\varepsilon$ 常逐步衰减。

> **理论补充：DQN 的历史地位。** Mnih et al.（2015, Nature）以 DQN 在 49 款 Atari 游戏中的约 29 款上达到或超过人类水平，是深度强化学习的里程碑。目标网络与经验回放是该论文的核心工程创新，至今仍是 DQN 家族（Double DQN、Dueling DQN、Rainbow）的公共基础。注意：2015 年原文的目标网络为周期性硬拷贝（每 C 步复制一次权重），软更新 $\mathbf{w}^-\leftarrow\tau\mathbf{w}+(1-\tau)\mathbf{w}^-$ 出自后续工作（如 DDPG），本文示例采用软更新，下面的代码亦沿用之。DQN 的 Q 网络训练本质仍是监督式回归（以贝尔曼目标为标签），损失仍用 MSE——前文优化工具在此复用。

**Python 示例**：DQN 核心更新（目标网络 + 经验回放）。

```python
import numpy as np

def dqn_update(model, target_model, batch, gamma=0.9, tau=0.001):
    """batch: 经验回放采样的小批量 (s, a, r, s', done)"""
    states, actions, rewards, next_states, dones = batch
    # 目标网络生成 y 目标（冻结权重，减少漂移）
    next_q = np.max(target_model(next_states), axis=1)
    targets = rewards + gamma * next_q * (1 - dones)
    # 训练 Q 网络：仅更新所选动作对应的 Q 值
    q_vals = model(states)
    q_vals[np.arange(len(states)), actions] = targets
    model.train_on_batch(states, q_vals)
    # 软更新目标网络权重：w⁻ ← τw + (1-τ)w⁻
    model_weights = model.get_weights()
    target_weights = target_model.get_weights()
    target_model.set_weights(
        [tau * m + (1 - tau) * t for m, t in zip(model_weights, target_weights)])
```

该函数体现了 DQN 稳定训练的两个关键机制：目标网络提供缓变的学习目标，经验回放的小批量打破序列相关性；软更新确保目标权重的平滑过渡。

## 总结：机器学习方法的比较与整体框架

综合全文，可从"问题类型—模型—优化—关键技巧"四个维度比较各方法：

| 方法 | 问题类型 | 模型 | 优化算法 | 关键技巧 |
|---|---|---|---|---|
| 线性回归 | 回归 | 线性函数 | 梯度下降 / 正规方程 | 特征缩放、L2 正则化 |
| 逻辑回归 | 二分类 | Sigmoid（对数线性） | 梯度下降 | 特征工程、L2 正则化 |
| softmax 回归 | 多分类 | Softmax（对数线性） | 梯度下降 | 数值稳定实现、正则化 |
| 神经网络 | 回归/分类/多标签 | 多层复合非线性 | 反向传播 + Adam | 正则化、Dropout、数据增强 |
| CNN | 图像分类/检测 | 卷积+池化+全连接 | 反向传播 | 局部连接、权值共享、池化 |
| 决策树/集成 | 分类/回归 | 树形结构 | 递归分裂（启发式） | 深度限制、剪枝、集成投票 |
| K-means | 聚类（无监督） | 质心模型 | 坐标下降 | 多次初始化选最优 |
| 异常检测 | 异常发现（无监督） | 高斯密度 | 参数估计 + 阈值 | 验证集 F1 选阈值 |
| 协同过滤 | 推荐 | 用户/物品向量点积 | 梯度下降 | 正则化、均值归一化 |
| 内容过滤 | 推荐 | 双神经网络点积 | 反向传播 | 特征工程 |
| DQN | 序贯决策（强化） | Q 网络 | 反向传播（贝尔曼目标） | 目标网络、经验回放 |

从模型看：线性回归、逻辑回归、Softmax 是对数线性模型；神经网络是多层非线性复合；决策树是非参数模型；K-means 与异常检测是密度/距离模型。从优化看：绝大多数方法的训练归结为损失函数的最小化——梯度下降及其变体（Adam）是贯穿全文的公共算法，而决策树、K-means 采用迭代/递归的启发式方法，DQN 以贝尔曼方程构造回归目标后仍用梯度下降。从泛化视角看：正则化（约束参数幅值）、数据（增强、合成、定向收集）、模型选择（交叉验证）与集成（多模型投票）是四类通用策略。

对初学者而言，建议的学习路径为：先掌握监督学习的基本框架与线性模型（回归与分类），理解梯度下降与损失函数设计的原理；再进阶到神经网络，重点理解激活函数的作用与训练细节；随后学习模型诊断方法论（偏差/方差、误差分析）——这是从"会调库"到"会构建系统"的关键一跃；最后按兴趣深入决策树与集成、无监督学习、推荐系统与强化学习等专题。机器学习方法的差异归根结底来自模型、策略与算法的不同，理解这一框架，即可系统把握整个学科。
